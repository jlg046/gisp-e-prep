Keep blueprint percentages authoritative. GISCI priority labels vary slightly between sections of the supplied companion materials, so Bucknell remediation should continue to use the official percentage weights.

Recommended use in review sessions

  1. Start with retrieval: ask students to explain concepts in their own words.
  2. Use GISCI's common misconceptions as discussion prompts and as inspiration for plausible multiple-choice distractors.
  3. Connect textbook procedures to software-agnostic principles.
  4. Use progress-check results to assign targeted textbook, ESRI, and GIS BoK follow-up.
