BUCKNELL GISP-E TEXTBOOK PATHWAY UPDATE

1. Unzip this package.
2. Upload the CONTENTS of Bucknell_GISPE_Complete_Website_Update to the root of your GitHub Pages repository, preserving folders.
3. Keep your existing assets/config.js file; this package intentionally does not include or replace it.
4. Delete student/workshops.html, admin/workshops.html, and the top-level workshops folder from GitHub because that pathway is retired.
5. Commit the upload, wait for GitHub Pages to deploy, then use Ctrl+F5.
6. Test student login, Recommended Focus, Missed Items, Textbook Pathway, chapter review downloads, ESRI Training, calendar, countdown, and admin login.
