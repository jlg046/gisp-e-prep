ORDER 43 — Guided Student Portal + GISCI Blueprint Companion Integration
Date: 2026-09-02

Purpose
- Make the website the primary operational home base for Fall 2026 preparation.
- Replace Textbook / ESRI / GIS Book of Knowledge as student top-level navigation items with a guided preparation model.
- Integrate the new GISCI Blueprint Companion Guide and Student Summary.

Student navigation
My Plan | My Progress | Practice Exams | Fall 2026 Calendar | Exam Blueprint & Study Guide | Study Resources

Key changes
1. My Plan is now the default student landing experience and automatically shows the current preparation week.
2. The weekly plan provides direct links to textbook chapter, mapped supplements, review session, assessment, Recommended Focus, and Study Resources.
3. New Exam Blueprint & Study Guide page summarizes the 11 weighted domains and GISCI's conceptual study guidance.
4. New Study Resources page consolidates Textbook, ESRI Training, and GIS Book of Knowledge access while preserving all existing source pages.
5. GISCI Student Summary PDF and full Companion Guide DOCX are bundled under resources/gisci.
6. The three cumulative review pages now include GISCI-style readiness questions and misconception checks.
7. Practice Exams page states the GISCI-confirmed multiple-choice format.
8. GIS Book of Knowledge coverage page supports chapter/domain filtering from direct links.
9. Administrator portal adds an Exam Blueprint & Study Guide reference page.

Unchanged
- All 18 production practice exams
- 120-minute timers
- Supabase schema and data
- Student/admin account behavior
- Cohort analytics, reactivation, and Delete Test
- assets/config.js
- Order 42 assessment/review cadence

Deployment
This is a full website package. For the cleanest deployment, replace the website files with this package while preserving your live assets/config.js values. No Supabase SQL is required.
