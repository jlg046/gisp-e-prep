GISP-E / PreGISP Preparation Program — Central Progress Version

WHAT CHANGED
- Separate Student Portal and Administrator Portal.
- Student username + PIN logins created by the administrator.
- Central Supabase database, so results follow students across browsers/devices.
- Exam submissions automatically save raw score, blueprint-weighted score, domain performance, and missed-item remediation.
- Administrator dashboard automatically reads current student results; no JSON export/import workflow.
- Exam 1 is treated as the recommended baseline, with later scores compared against it.
- Six current 75-question applied GIS/geospatial practice exams are integrated.
