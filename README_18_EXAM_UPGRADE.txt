GISP-E / PreGISP 18-Exam Upgrade

Structure: six exam sets, each with A Standard, B More Challenging, and C Difficult versions (18 x 75 = 1,350 presented questions). The original six exams are retained as the A tier; 900 new B/C question stems are included.

IMPORTANT FOR AN EXISTING SUPABASE INSTALLATION: run MIGRATE_TO_18_EXAMS.sql once in Supabase SQL Editor before deploying the new website files. This expands the exam_attempts table and RPC functions to store exam set and difficulty.

The student Practice Exams page is grouped by exam set. Exam 1A is the recommended baseline. Student and administrator trackers display exam difficulty separately.

C-level exams are intentionally mastery challenges and should not be represented as a prediction of actual GISP-E difficulty.
